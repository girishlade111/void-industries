THE BRIEF

A LABEL THAT SOUNDS LIKE IT LOOKS.

Signal Decay is an independent electronic label releasing music that's deliberately imperfect — tape hiss, clipping, formats falling apart. Their previous identity was clean and forgettable, the exact opposite of the catalog.

We built an identity that behaves like degraded media: type that loses fidelity under stress, a logo that fragments at small sizes, and a packaging system where every print run introduces "errors" on purpose.

"The system is designed to break — and every break is a feature we specified."

The web component pushes the same logic: a discography interface where album art decays the longer the page sits open, and recovers when you refresh. Nothing is static; everything has a half-life.
